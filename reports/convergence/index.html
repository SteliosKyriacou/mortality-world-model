How every training run converged

Each run records its losses every few epochs and, at checkpoints, measures what matters: forecast error on validation and held-out people, and how far the learned drift is from the true equation. A falling loss is not enough. A run has converged in a useful sense only when those numbers stop improving.

3. The long runs

Three long runs, epochs on a log scale. The first long Model A run kept a high learning rate (2×10⁻³) for thousands of epochs and blew up at epoch 1,855. The second used 5×10⁻⁴ and a penalty on steep drift; it stayed stable but overfit and was stopped at epoch 2,000. A matching long run with the HetGNN encoder answers whether the graph encoder changes this. The long Model B run was stopped at epoch 18,368.
